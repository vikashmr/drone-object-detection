# 🚁 Autonomous Drone Object Detection

A real-time computer vision system capable of detecting objects (people, vehicles, obstacles) from aerial feeds.

## 🚀 Tech Stack
- **Python 3.10**
- **YOLOv8** (State-of-the-art Object Detection)
- **OpenCV** (Video processing)

## 🛠️ How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the detector: `python drone_detect.py`
